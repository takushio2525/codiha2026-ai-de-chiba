# CHIZUBA 利用説明書

**CHIZUBA（ちずば）の使い方**。画面の見方と、やりたいことの手順を書いてある。

CHIZUBA は千葉県の地図に、**行政のオープンデータ**（避難場所・AED・子育て施設・景観100選）と、
**住民と行政の投稿**（危険箇所・浸水・観光おすすめ）を重ねて見られるウェブサイト。

- **閲覧はログイン不要。** ログインが要るのは投稿・コメントのときだけ
- スマートフォンからでも PC からでも使える（画面の並びが変わる）
- 対応は千葉県全域。**デモデータは市川市**

仕組みの説明（開発者向け）は [`docs/spec/`](../spec/README.md)。

## 起動のしかた（審査員・開発者向け）

```bash
cd app
docker compose up
```

ブラウザで <http://localhost:3000> を開く。**これだけ。**
アカウント登録も API キーの取得も要らない。

3000 番が塞がっているときだけ:

```bash
cd app && CHIZUBA_PORT=3100 docker compose up
```

止めるときは `Ctrl+C`、片付けるときは `docker compose down`。
**`docker compose down -v` は投稿・写真・ログイン状態を全部消す**ので注意。

## この説明書のスクリーンショットについて

- **すべて実際に動かして撮った**もの（2026-09-03・デモデータのみ）
- 写っている「デモ住民A」「デモ市役所 道路担当」などは
  **起動時に入っているデモ用のアカウント**で、実在の人物ではない
- 「デモ投稿」の印が付いている投稿は**動作確認のために用意したもの**で、
  実際の通報ではない
