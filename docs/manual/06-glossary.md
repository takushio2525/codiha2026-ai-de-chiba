# 06. 用語集

この説明書と画面に出てくる言葉。**五十音順ではなく、種類ごと**に並べてある。

---

## CHIZUBA の言葉

| 言葉 | 意味 |
|---|---|
| **CHIZUBA（ちずば）** | このサービスの名前。**CHI**ba ＋ **ZU**（地図）＋ **BA**（場） |
| **防災マップ** | ハザードマップ・避難場所・危険箇所の報告を出す画面（既定） |
| **観光マップ** | 景観100選・観光おすすめの投稿を出す画面 |
| **操作パネル** | 表示の切り替え・投稿・検索・書き出しをまとめた面。PC では左に固定、スマホでは下から出るシート |
| **投稿** | 住民または行政が地図に置いた情報。**危険箇所・浸水・観光おすすめ**の 3 種類 |
| **対応状況** | 行政が付ける 4 段階（未対応／受付／対応中／対応済） |
| **注意案内** | 過去の浸水報告と雨の予報を並べて出すお知らせ。**予測ではない** |
| **デモ投稿** | 起動した直後から機能を試せるように入れてある投稿 22 件。**実際の通報ではない** |
| **デモログイン** | 表示名を入れるだけでログインできる仕組み |
| **デモモードで動作中** | Google の認証キーが設定されていない環境であることを示す表示 |
| **行政ユーザー** | 担当する市町村の投稿に公式コメントと対応状況を付けられる人 |
| **一般ユーザー** | 住民・来訪者。投稿とコメントができる |

## 地図の言葉

| 言葉 | 意味 |
|---|---|
| **ハザードマップ** | 災害が起きたときに想定される被害を地図にしたもの。CHIZUBA では**浸水想定**（洪水・高潮・津波）と**土砂災害警戒区域**（急傾斜地の崩壊）を重ねる |
| **浸水想定区域** | その災害が起きたときに水に浸かると想定される範囲。**公表されていない河川・地域もある** |
| **浸水深** | 浸かる水の深さ。凡例の色で表す。**洪水は 6 段階、津波・高潮は 8 段階** |
| **指定緊急避難場所** | 災害の種類ごとに、逃げ込める場所として市が指定している施設 |
| **タイル** | 地図を小さな正方形の画像に切り分けたもの。表示範囲に応じて必要なぶんだけ取る |
| **ズーム（縮尺）** | 地図の拡大の度合い。数字が大きいほど拡大 |
| **レイヤー** | 地図に重ねる層。CHIZUBA では背景地図・ハザード・施設・投稿などが層になっている |
| **ポップアップ** | 地図の点を押したときに出る吹き出し |
| **凡例** | 色と意味の対応表 |
| **不透明度** | 重ねた層の濃さ。下の地図をどれだけ透かすか |

## データの言葉

| 言葉 | 意味 |
|---|---|
| **オープンデータ** | 誰でも自由に使える形で公開されたデータ。CHIZUBA は市川市と千葉県のものを使う |
| **GeoJSON** | 位置情報を持ったデータの標準形式。地図ソフト（QGIS など）でそのまま開ける |
| **CSV** | 表形式のデータ。Excel や Google スプレッドシートで開ける |
| **CC BY 4.0** | 「**出典を書けば**自由に使ってよい」というライセンス。市川市のデータがこれ |
| **PDL1.0（公共データ利用規約）** | 国や自治体のデータでよく使われるライセンス。**出典の記載が条件** |
| **CC0** | 「著作権を放棄した」に近い扱い。出典を書かなくても使える |
| **CC BY-SA** | 出典を書き、**同じ条件で公開する**ことが条件 |
| **出典（クレジット）** | データや写真の出どころ。CHIZUBA では地図の右下と `/about` に出す |
| **属性（プロパティ）** | 地点が持つ情報（名前・住所・電話など） |

## 気象の言葉

| 言葉 | 意味 |
|---|---|
| **アメダス** | 気象庁の自動観測システム。全国 1,286 地点（2026-09-03 時点の実測） |
| **1 時間降水量** | 直前 1 時間に降った雨の量（mm）。CHIZUBA の「雨量」はこれ |
| **降水確率** | 気象庁が 6 時間ごとに 10% 刻みで出す。CHIZUBA は**今後 24 時間の最大値**を見る |
| **予報区** | 気象庁が予報を出す単位。千葉県は「**北西部 / 北東部 / 南部**」の 3 区分が最小。**市町村単位では出ない** |
| **気象業務法** | 気象庁以外が予報を業として出すことを許可制にしている法律。CHIZUBA が「予測」を書かない理由 |

## 技術の言葉（審査員から聞かれたとき用）

| 言葉 | 意味 |
|---|---|
| **Docker** | アプリと必要なもの一式をまとめて動かす仕組み。CHIZUBA は `docker compose up` で起動する |
| **コンテナ** | Docker が動かす単位。CHIZUBA は **web（アプリ）と db（データベース）の 2 つ** |
| **PostgreSQL** | データベース。CHIZUBA は投稿・ユーザー・市町村を保存する |
| **ボリューム** | コンテナを作り直しても消えない保存領域。CHIZUBA は 2 つ（データベース用と写真用） |
| **Next.js / React** | 画面を作るための仕組み |
| **MapLibre GL JS** | 地図を描くライブラリ。**認証キーが要らない**オープンソース |
| **OSRM** | 経路を計算するサービス。**認証キーが要らない** |
| **API** | プログラム同士のやりとりの窓口。CHIZUBA は投稿の取得・作成などに使う |
| **セッション** | ログイン状態。CHIZUBA では暗号化された Cookie で保持する |
| **Cookie** | ブラウザがサイトごとに覚えておく小さなデータ |
| **Exif** | 写真に埋め込まれる撮影日時・位置情報。**CHIZUBA は消さない**ので注意 |
| **市町村コード** | 全国の市区町村に振られた 5 桁の番号（JIS X 0402）。市川市は **12203** |

## 略号

| 略号 | 読み・意味 |
|---|---|
| **AED** | 自動体外式除細動器。心停止のときに使う装置 |
| **F-1〜F-8** | この開発での機能の番号（仕様書で使う）。F-1 ハザードマップ／F-2 危険箇所／F-3 浸水／F-4 注意案内／F-5 観光マップ／F-6 観光おすすめ／F-7 行政の応答／F-8 ログイン |
| **S-1〜S-8** | 画面の番号。S-1 防災マップ／S-2 観光マップ／S-3 投稿の詳細／S-4 投稿フォーム／S-5 投稿一覧／S-6 ログイン／S-7 出典／S-8 プライバシー |
| **JST** | 日本標準時。CHIZUBA の日付と時刻はすべてこれ |
| **CODIHA** | ちばオープンデータアイデアソン・ハッカソン |
