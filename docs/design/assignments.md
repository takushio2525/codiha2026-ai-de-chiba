# 担当表（記入テンプレ）

**コードを書き始める前に、この表を全部埋める。「未定」が 1 つでも残っている状態で
実装に入らない。** 切り方の考え方は [`../before_coding.md`](../before_coding.md) を読む。

**副担当**は「主担当が倒れたときに引き継げる人」。1 人しか分からない状態を作らないために置く。
最低限、副担当は主担当のコンポーネントの README を読んで、ビルドと実行ができる状態にしておく。

## 分担が正しく切れているかの確認

書き終えたら、全員で次を確認する。

- [ ] 各コンポーネントの「入力 → 出力」が 1 行で書けている
- [ ] **2 人以上が同じディレクトリを主担当にしていない**
- [ ] どのコンポーネントも、相手の完成を待たずにダミーデータで動作確認できる
- [ ] 全員に主担当が 1 つ以上ある（誰も「手が空いている人枠」になっていない）
- [ ] コンポーネント間のつなぎ目が [`interfaces.md`](interfaces.md) に列挙されている

## 変更したら

担当を途中で変えるのは問題ない（よくある）。ただし**変えたらこの表を更新して PR を出す**。
表と実態がズレると、レビュー依頼の宛先が分からなくなる。
