### 異常時の約束

- 受け取ったデータが壊れていたら → （例: そのフレームを捨てて、直前の値を使い続ける）
- 一定時間データが来なかったら → （例: 500ms 無通信で「切断」と判断し、安全状態へ）
- 範囲外の値が来たら → （例: 範囲にクリップする / ログに出して無視する）

**「異常時にどうするか」を決めていないと、結合テストで必ず揉める。** ここを空白にしない。
