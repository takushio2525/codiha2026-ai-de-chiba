# 作業履歴

> **書き方**: 作業が一段落したら**追記**する（上書きしない）。
> 1 エントリ **1〜3 行**に収める。詳細は git log とコミットメッセージに任せる。
> 単発の質問やタイポ修正では更新しない。
>
> 古いエントリが 30 件を超えたら `progress-archive.md` に移す。
