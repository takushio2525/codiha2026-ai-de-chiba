## コンポーネントと担当

詳細は `docs/design/assignments.md`。ここには**コードの置き場所**を書く。

| コンポーネント | 置き場所 | 単独で動かす方法 |
|---|---|---|
| 〈例: ファームウェア〉 | `firmware/node_01/` | `cd firmware/node_01 && pio run` |
| 〈例: PC アプリ〉 | `pc_app/example_viewer/` | Processing IDE で開いて Run |

## コンポーネント間のデータ形式

**正本は `docs/design/interfaces.md`。** ここには要点だけ書く。

| つなぎ目 | 形式 | 頻度 |
|---|---|---|
| 〈例: マイコン → PC〉 | `STATUS,<整数>\n` | 100ms 周期 |

**この形式を変える変更は影響が広い。** 送る側と受け取る側を必ず同時に直す。

## マイコン側の設計パターン（EMA）

`firmware/` を使う場合、EMA（Embedded Module Architecture）に従う。

- `loop()` は「入力 → ロジック → 出力」の 3 フェーズ固定
- ハードウェアごとに `IModule` を継承したモジュールを書く
- **モジュール同士を直接呼ばない。** やり取りは `SystemData` 経由

詳細と実装手順: `firmware/common/lib/ModuleCore/README.md`
