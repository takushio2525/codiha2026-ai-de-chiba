# deploy/ — 動かしっぱなしにするための手順とスクリプト

**提出物ではない。** CODIHA に提出するのは `app/` 配下だけで、このディレクトリは
提出アーカイブに入らない（`tools/package_submission.sh` は `app/` しか固めない）。
ここにあるのは「作ったものを審査員や来場者に触ってもらうため」の運用手順。

| 場所 | 何があるか |
|---|---|
| [`selfhost/`](selfhost/README.md) | 自宅の Mac で常時稼働させ、**Tailscale Funnel** で公開する一式（手順書・セットアップスクリプト・QR 生成） |
