# results — 計測結果の置き場

`serial_logger.py` が出した CSV と、`evaluate.py` が出したレポート・グラフを置く。

## ファイル名の付け方

**条件が分かる名前にする。** あとから見て条件が分からないデータは報告書に使えない。

```
run_001_5台_USB給電.csv
run_002_5台_電池駆動.csv
report_001.md
run_001.png
```

## 記録するときの約束

| やること | なぜ |
|---|---|
| 同じ条件で最低 3 回は取る | 1 回だけだと、たまたま良かった / 悪かったのか分からない |
| 失敗した回のデータも残す | 「10 回中 2 回失敗」は立派な評価結果。都合の良いデータだけ残すのは改ざん |
| 計測条件を `metrics.md` に書く | 台数・電源・場所が違うと数字を比較できない |

## サイズに注意

長時間の計測 CSV は数 MB になることがある。何十本もコミットするとリポジトリが
重くなるので、**報告書に使うものだけ残して、途中経過は削除してよい**。
どうしても大量に残すなら `.gitattributes` の Git LFS を検討する。
